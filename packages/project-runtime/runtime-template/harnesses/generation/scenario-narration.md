# Scenario Narration Step

Purpose: narrate backend-owned scenario skeletons only. Do not change scenario identity, classification, workflow, path, edge, precondition references, action references, assertions, ordering, kind, or coverage.

Use only persisted skeleton/WIKI receipts. Keep observations append-only within this session and do not restate prior context. Initial authoring submits one complete narration patch. A correction submits only the scenario refs in the backend scope, echoes its base hash, and uses only source ranges connected to those scenario paths. A response, tool success, or agent end does not complete the step.
