# Business Catalog Step

Purpose: group every frozen workflow into exactly one human-readable business classification. Do not alter workflows, edges, goals, or scenarios.

Use only persisted workflow-skeleton and common-WIKI receipts. Keep observations append-only within this session and do not restate prior context. Initial authoring assigns every workflow exactly once. A correction returns only the workflow-label assignments in the backend scope and echoes its base hash; the backend preserves all other assignments. A response, tool success, or agent end does not complete the step.
